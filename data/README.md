# Data

The full validated analytical data used by the project is stored in `../powerbi/powerbi_ready_data/`.

This folder contains small 25-row samples for GitHub browsing. The full 200,000-encounter dataset is included in the Power BI-ready files.

Raw working extracts and the local SQLite database are intentionally excluded from the GitHub package to avoid duplicate large files and temporary build artifacts. The generation and cleaning scripts remain available under `python/`.
